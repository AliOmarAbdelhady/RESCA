## 5. Methodology, Lookup Evidence & Source URLs

### Domain Verification Protocol (Executed 2026-11-25 UTC/EET)
1. **`.com` Authoritative Registry Check:** Queried Verisign RDAP (`https://rdap.verisign.com/com/v1/domain/<domain>`) where HTTP `404` indicates no registration record and HTTP `200` confirms active registration. Paired every query with live DNS `dig +short NS <domain>`.
2. **Double-Verification of Top Finalists:** Re-queried Top 5 + runners-up directly via TCP port 43 against `whois.verisign-grs.com` (`domain <name>.com`), confirming `No match for domain "...".` for every recommended `.com`.
3. **Multi-TLD Verification (`.ai`, `.io`, `.app`, `.co`, `.org`, `.net`, `.tech`, `.dev`):**
   - `.ai` & `.io`: Identity Digital RDAP (`https://rdap.identitydigital.services/rdap/domain/<domain>`) + `whois.nic.ai` / `whois.nic.io` + `dig +short NS`.
   - `.app` & `.dev`: Google Registry RDAP (`https://pubapi.registry.google/rdap/domain/<domain>`) + `dig +short NS`.
   - `.co`: Direct TCP port 43 WHOIS (`whois.registry.co`) + `dig +short NS`.
   - `.org` / `.net` / `.tech`: PIR RDAP (`https://rdap.publicinterestregistry.org/rdap/domain/`), Verisign `.net` RDAP, and `whois.nic.tech`.
4. **Positive Control Calibration:** Verified that known registered domains return HTTP `200` on the exact same RDAP endpoints before trusting `404` results: `x.ai` (`200`), `github.io` (`200`), `cash.app` (`200`), `angel.co` (WHOIS record returned), and `rescuevision.com` (`200`, NS `ns05/ns06.domaincontrol.com`, HTTP redirect to `https://www.medicalalert.com/`).
