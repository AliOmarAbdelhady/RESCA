# Report references

One line per source: `key | IEEE entry`. Cite a source in any Markdown section as `[@key]`.
`build_report.py` numbers the cited sources in order of first citation across the whole
report, rewrites every citation and rebuilds the reference list. Sources that nothing cites
are left out of the list. `*text*` is set in italics. Web pages carry the date they were
last opened.
