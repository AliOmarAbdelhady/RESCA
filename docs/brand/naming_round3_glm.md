## 5. Method

1. Generate: one-letter mutations and extensions of RESCA, same-shape analogues, Arabic, Latin and Greek roots, English blends — 523 candidates in families A–F, plus 60 ruled out in family G.
2. Check every shortlisted name against the live Verisign RDAP for the bare `.com` and record the code and UTC time.
3. Keep only `404`. For those, run quick web searches for conflicts in emergency services, drones, GIS, AI and medicine, and check the Arabic and English meaning.
4. Rank what survives and give one recommendation.
